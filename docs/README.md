# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
   
# Общее описание решения
В geometric_lib есть файлы circle.py, rectangle.py, square.py, triangle.py.  

В circle.py написаны функции, которые позволяют вычислить площадь круга и длину окружности. 

В rectangle.py написаны функции, которые позволяют вычислить площадь и периметр прямоугольника. 

В square.py написаны функции, которые позволяют вычислить площадь и периметр квадрата. 

В triangle.py написаны функции, которые позволяют вычислить площадь и периметр треугольника.

# Описание функций
## Функции из файла rectangle.py
1. def area(a, b)
- вычисляет площадь прямоугольника по заданным сторонам
- входные данные: две стороны прямоугольника
- выходные данные: площадь прямоугольника
- пример вызова:   
```python
print(area(1, 2)) #выведет 2 
```
2. def perimeter(a, b)
- вычисляет периметр прямоугольника по заданным сторонам
- входные данные: две стороны прямоугольника
- выходные данные: периметр прямоугольника
- пример вызова:   
```python
print(perimeter(1, 2)) #выведет 6
```

## Функции из файла triangle.py
1. def area(a, h)
- вычисляет площадь треугольника по заданным стороне и высоте
- входные данные: сторона и высота треугольника
- выходные данные: площадь треугольника
- пример вызова:   
```python
print(area(1, 2)) #выведет 1 
```
2. def perimeter(a, b, c)
- вычисляет периметр треугольника по заданным сторонам
- входные данные: стороны треугольника
- выходные данные: периметр треугольника
- пример вызова:   
```python
print(perimeter(1, 2, 3)) #выведет 6
```
## Функции из файла circle.py
1. def area(r)
- вычисляет площадь круга по заданному радиусу
- входные данные: радиус круга
- выходные данные: площадь круга
- пример вызова:   
```python
print(area(2)) #выведет 12.566370614359172
```
2. def perimeter(r)
- вычисляет длину окружности по заданному радиусу
- входные данные: радиус окружности
- выходные данные: длина окружности
- пример вызова:   
```python
print(perimeter(2)) #выведет 12.566370614359172

```
## Функции из файла square.py
1. def area(a)
- вычисляет площадь квадрата по заданным сторонам
- входные данные: сторона квадрата
- выходные данные: площадь квадрата
- пример вызова:   
```python
print(area(2)) #выведет 4
```
2. def perimeter(a)
- вычисляет периметр квадрата по заданным сторонам
- входные данные: сторона квадрата
- выходные данные: периметр квадрата
- пример вызова:   
```python
print(perimeter(2)) #выведет 8
```
